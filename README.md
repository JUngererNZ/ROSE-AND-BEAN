# Rose & Bean Landing Page

A warm, editorial single-page marketing site for **Rose & Bean**, a countryside coffee shop and farm destination in Monteseel, South Africa.

## Project Overview

This project is a static website designed to feel like a premium lifestyle or wellness brand: refined, human, and inviting. The layout uses a serif headline font paired with a clean sans-serif body font, supported by an earthy colour palette of cream, terracotta, warm taupe, and deep brown.

The site was built as a simple static experience for initial hosting on GitHub Pages, with a lightweight `index.html` file that redirects to the main landing page.

## Site Content

The page is structured into four main areas:

- **Hero section** with an editorial headline, short supporting copy, and a clear call-to-action.
- **Feature / about section** with three columns that highlight the experience, atmosphere, and hospitality.
- **Testimonial section** with large pull-quote styling and selected guest reviews.
- **Footer** with navigation links and a newsletter email input.

## Design Direction

The visual direction is intentionally soft, spacious, and sophisticated:

- Warm gradients and subtle tonal shifts.
- Generous whitespace and fine divider lines.
- No harsh shadows or bright neon accents.
- Responsive layout for mobile, tablet, and desktop.

## File Structure

- `index.html` — Basic entry page for GitHub Pages; redirects to the main landing page.
- `rose-and-bean-landing.html` — The primary single-page landing page with embedded CSS.
- `README.md` — Project overview and usage notes.

## Hosting

The site is ready to be hosted on GitHub Pages. Point the repository’s Pages settings to the root of the main branch so that `index.html` loads first and resolves to the landing page automatically.

## Notes

This site is a static front-end concept and does not require a build step or framework. It can be edited directly in plain HTML and CSS.
